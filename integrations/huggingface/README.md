# DebateKit - Multi-AI Brainstorming

Consult a council of AI models that debate, analyze, and solve problems together. Each query is discussed by multiple AI participants, then synthesized by a moderator into actionable insights.

## Tools

- **Consult Council** - Ask any question and get perspectives from multiple AI models
- **Code Review** - Get a multi-model code review with focus on security, performance, and best practices
- **Assess Tradeoffs** - Compare options with structured pros/cons analysis

## Setup

Set your `DEBATEKIT_API_KEY` environment variable (get one at [debatekit.ai](https://debatekit.ai)).
