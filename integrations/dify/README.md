# DebateKit — Dify Plugin

Multi-model AI debates for Dify. GPT-4o, Claude, Gemini, and 200+ models discuss your question in sequence, then a moderator synthesizes all perspectives into actionable insight.

## Tools

| Tool | Description |
|------|-------------|
| **Consult Council** | Multiple AI models debate your question sequentially, then a moderator synthesizes all perspectives. |
| **Review Code** | Multi-model code review with configurable focus areas and severity levels. |
| **Debug Issue** | Collaborative multi-model debugging — each model analyzes the issue from a different angle. |
| **Plan Implementation** | Generate an implementation plan with task breakdown, dependencies, and risk assessment. |
| **Design Architecture** | Multi-model architecture design session with pattern recommendations and tradeoff analysis. |
| **Assess Tradeoffs** | Structured tradeoff analysis across multiple options with weighted scoring. |

## Configuration

1. Get an API key at [debatekit.com/chat/settings/api-keys](https://debatekit.com/chat/settings/api-keys)
2. Install the plugin in your Dify workspace
3. Enter your API key (`rpnd_xxxxxxxxxxxx`) in the plugin credentials
